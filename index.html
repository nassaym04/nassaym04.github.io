Exercices — Temps de vol

Suite de Syracuse : si le nombre est pair, on le divise par 2 ; s'il est impair, on calcule 3 × n + 1. On recommence jusqu'à 1.

Q1

Calculer le temps de vol

Écrire une fonction temps_de_vol(n) qui renvoie le nombre d'étapes nécessaires pour arriver à 1.

def temps_de_vol(n):
    compteur = 0

    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1

        compteur = compteur + 1

    return compteur

Exemple : pour 6, la suite est 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1. Il y a donc 8 étapes.

Q2

Trouver le plus grand temps de vol

Écrire une fonction temps_max(nmax) qui affiche le plus grand temps de vol pour un nombre entre 1 et nmax.

def temps_max(nmax):
    maximum = 0

    for n in range(1, nmax + 1):
        temps = temps_de_vol(n)

        if temps > maximum:
            maximum = temps

    print(maximum)

On parcourt tous les nombres avec for, on calcule leur temps de vol, puis on conserve la plus grande valeur dans maximum.

Q3

Afficher aussi le nombre de départ

Modifier la fonction pour afficher le nombre qui donne le plus grand temps de vol.

def temps_max(nmax):
    maximum = 0
    nombre_max = 0

    for n in range(1, nmax + 1):
        temps = temps_de_vol(n)

        if temps > maximum:
            maximum = temps
            nombre_max = n

    print("Le plus grand temps de vol est", maximum)
    print("Il est obtenu pour le nombre", nombre_max)

La variable nombre_max mémorise le nombre de départ chaque fois qu'un nouveau maximum est trouvé.
