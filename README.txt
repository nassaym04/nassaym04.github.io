# Mon espace NSI

Site statique de portfolio pour présenter un travail de Première NSI.

## Contenu
- Accueil
- Notions Python
- Fiche de révision
- Exercices Q1, Q2 et Q3 sur le temps de vol / Syracuse
- Explications affichables
- Petit outil interactif pour calculer le temps de vol

## Utilisation
Ouvrir `index.html` dans un navigateur.

## Mise en ligne
Le dossier peut être publié gratuitement avec GitHub Pages. Il suffit de créer un dépôt GitHub, d'y déposer `index.html` et `style.css`, puis d'activer Pages.
